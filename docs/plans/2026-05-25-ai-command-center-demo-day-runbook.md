# AI 指挥中心客户演示当天 Runbook

日期：2026-05-25

## 1. 演示前 10 分钟检查

1. 打开 `https://zhefenglin.com/api/health`，预期返回 `{"status":"ok"}`。
2. 用 admin 账号登录 `https://zhefenglin.com`。
3. 打开 `/ai-command-center`，确认页面加载成功。
4. 确认左侧侧边栏有 `AI 指挥中心` 和 `AI 审计日志`。
5. 确认 `/ai-command-center` 展示资产包数量、待处理任务、待审批事项、今日 Agent 执行。
6. 确认 AI 今日判断中能看到 `rules_based`、置信度、`需人工复核`、Evidence。
7. 打开 `/admin/ai-audit-logs`，确认规则阈值配置、复盘闭环、AI 决策审计日志可见。
8. 不在演示前临时保存阈值、不临时提交复盘、不临时新增不可控 Agent run。

## 2. 推荐演示路径

1. 从首页进入 `AI 指挥中心`。
2. 讲今日总览：说明系统把资产、任务、审批和 Agent 执行集中到一个指挥视图。
3. 讲 AI 今日判断：展示 summary、关键发现、建议动作、风险提示。
4. 讲 Evidence：强调所有建议都有来源、对象、计算依据和数据质量说明。
5. 讲 Agent 工作台：展示 8 个 Agent，说明当前是半自动、可复核、可审计的 Agent 化工作流。
6. 讲对话式指挥入口：展示自然语言入口，但优先使用现有输出讲解，避免临场生成不可控内容。
7. 讲最近 Agent run：展示每次运行可追踪。
8. 切到 `AI 审计日志`。
9. 讲规则阈值配置：说明阈值可治理、可版本化，不把关键数值交给 LLM 拍脑袋。
10. 讲复盘闭环：说明人工反馈会沉淀为运营复盘，而不是自动替代人工决策。
11. 讲 AI 决策审计日志：展示 `decision_type`、`action`、Run、人工复核和结果摘要。

## 3. 客户演示话术

- 这套系统的定位是汽车金融不良资产处置的 AI 指挥中心，不是普通聊天机器人。
- AI 只生成分析、建议、任务草稿、报告草稿、成本预警和复盘记录。
- 系统不会自动接受买方报价、批准资产出让、批准高成本估值、导出敏感数据、删除数据或替代法律结论。
- 高影响动作都保留人工复核，页面和审计记录都会标记 `requires_human_review=true`。
- 价格、成本、覆盖率、处置路径、现金流等关键数值来自规则和服务层计算，LLM 只负责解释和草稿表达。
- 所有 Agent 运行、阈值变更、人工复盘和审计记录都在租户边界内留痕。

## 4. 演示时不要做的事

- 不承诺 AI 自动成交、自动审批或自动出具法律结论。
- 不在客户面前临时修改阈值并保存。
- 不在客户面前临时提交复盘，除非已经准备好可公开展示的样例数据。
- 不展示真实敏感字段、密钥、生产环境变量或数据库后台。
- 不把 mock、fallback 或规则化输出说成完全自主规划。

## 5. 常见问题回答

问：AI 能不能直接决定资产包出让价格？

答：不能。系统会给出测算依据、价格区间、风险提示和谈判建议，正式价格必须走人工审批。

问：能不能自动接受买方报价？

答：不能。系统可以反推报价合理性和风险折价，但接受报价属于高影响动作，必须人工确认。

问：如果 LLM 不可用会不会影响业务？

答：不会影响核心规则化分析。系统会回退到 fallback 结构，并在 evidence 中说明未调用外部 LLM。

问：怎么保证租户隔离？

答：Agent run、审计日志、资产包、任务和成本数据都按 `tenant_id` 过滤，角色权限还会影响可见字段。

问：后续怎么从分析走向运营闭环？

答：下一步重点是任务草稿确认、阈值版本治理、复盘数据沉淀和规则优化建议，仍保持人工确认边界。

## 6. 故障兜底

### 页面打不开

1. 访问 `/api/health`。
2. 如果 health 正常，刷新页面或重新登录。
3. 如果 health 异常，暂停演示生产操作，改用已保存截图和交付记录说明能力。

### AI 指挥中心无数据

1. 确认是否使用 admin 或 manager 账号。
2. 说明空状态是安全设计，不跨租户读取其他数据。
3. 切换到已有截图或历史 Agent run 展示审计链路。

### 审计日志为空

1. 确认当前租户是否已有 Agent run。
2. 说明审计日志按租户隔离，空数据不代表功能缺失。
3. 展示规则阈值配置和复盘闭环区域，强调所有新动作会写入审计。

### 客户要求现场自动化动作

统一回答：当前阶段坚持金融级 human-in-the-loop，系统只生成建议和草稿，正式动作必须由授权人员确认。
